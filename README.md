# hospital-management-system-mvp
A modern frontend Hospital Management System (MVP) built with HTML, CSS, and JavaScript featuring dashboard analytics, patient management, doctor management, and appointment scheduling.
Economic Medi Flow Pro
Hospital Management System (Frontend MVP)
📌 Project Overview

Economic Medi Flow Pro is a modern, responsive Hospital Management System (HMS) designed as a Minimum Viable Product (MVP).

The system focuses on improving hospital workflow efficiency by providing structured management of:

Patients

Doctors

Appointments

Dashboard analytics

This project is built using pure HTML, CSS, and JavaScript without frameworks, emphasizing clean UI/UX and modular frontend architecture.
